# yj1438.github.io

个人博客。Jekyll + minima 主题，push 到 master 后由 GitHub Pages 自动构建发布。

- 2015–2018 年旧版博客（60 篇文章、手写布局、VR/Flexbox demo 等）归档在 `archive-2015-2018` 分支。

## 本地预览

```bash
bundle install
bundle exec jekyll serve
```

## 发布新文章

在 `_posts/` 下新建 `YYYY-MM-DD-标题.md`（头部带 title/date/categories），push 即发布。
